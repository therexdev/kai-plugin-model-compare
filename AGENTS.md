This is a KAI Foundation v3 plugin. It owns its UI, feature engine, dependencies, and plugin-scoped saved data. Native service code runs with full user and application access and must be explicitly trusted during installation; do not describe it as sandboxed. The renderer remains sandboxed and uses window.kai.call. Use documented Foundation APIs and declared service contracts; do not import Core internals or other plugins' private stores. Bundle dependencies at author build time, never install them on a user's machine. Never commit secrets or publisher private keys. Old application data is not migrated or deleted. Run tests and package verification before publication.
